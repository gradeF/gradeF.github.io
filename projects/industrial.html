1

시스템 구조 리팩토링을 통한 결합도 해소

개발 의도. 여러 서브 시스템을 통합하는 과정에서 프레임드랍이 다수 발생했고, 잦은 싱글톤 사용으로 기능 수정 시 영향 범위 파악이 어려운 유지보수 문제가 누적됐습니다.

  • Manager.instance가 씬 전환·키보드·번역·사운드·네트워크·WebRTC·드로잉·이미지/PDF 뷰어를 모두 직접 소유하던 구조를 발견
  • Manager 싱글톤 → 이벤트/옵저버 패턴으로 전환해 매니저 간 직접 참조를 최소화
구조 전환 결과, 기능 추가에 필요한 소요 시간이 눈에 띄게 줄었습니다.
2

실시간 네트워크 및 커뮤니케이션 시스템 구현

개발 의도. PC 사용자와 AR 사용자 간의 실시간 화면 공유를 위해 구현했습니다.

  • Photon — 룸 매칭/시그널링, 드로잉 좌표 스트리밍
  • WebRTC (Microsoft MixedReality-WebRTC 기반) — AR 사용자의 카메라 뷰·음성을 PC로 실시간 스트리밍
WebRTC 연결 구조

트러블슈팅. WebRTC 네이티브 라이브러리와 빌드 타겟 아키텍처(arm32/arm64)가 맞지 않아 연결이 맺어지지 않는 문제가 있었고, 빌드 타겟 아키텍처를 고정해 해결했습니다.
3

절차적 AR 콘텐츠 및 인터랙션 개발

개발 의도. 통제된 현장에서는 관리자가 직접 왕복 대응하는 데 시간이 오래 걸려 즉각적인 문제 해결이 어려웠습니다. 현장에 처음 투입되는 작업자가 AR 매뉴얼을 참고해 스스로 순서대로 작업하고, 문제 발생 시에만 관리자에게 연락하도록 개발했습니다.

  AR_Manager --> ScreenView : RawImage
  AR_Manager --> SpotLightHighlight : 공간 하이라이트
  AR_Manager --> WarningNotice : TMP_Text
  • CSV로 정의된 단계별 데이터(버튼 위치, 화면 이미지, 설명, 경고)를 CSV_Manager가 읽고, AR_Manager가 CurStep에 따라 순서대로 재생
  • 단계마다 공간상 특정 위치를 스팟라이트로 하이라이트, 화면 이미지 페이드 전환, 설명 텍스트 표시
  • 핸드트래킹(MRTK) 조작 및 드로잉 주석 인터랙션 결합
콘텐츠가 코드에 하드코딩되지 않고 CSV로 분리되어, 기획자가 직접 절차 내용을 수정할 수 있습니다.
