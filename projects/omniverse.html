1

Web–Omniverse 실시간 스트리밍 시스템 구축

개발 의도. 고사양 GPU 없이도 브라우저만으로 Omniverse 3D 씬에 접근해 실시간으로 협업할 수 있는 환경이 필요했습니다. 별도 클라이언트 설치나 3D 뷰어 없이, 웹 브라우저에서 Omniverse Kit 앱을 원격 스트리밍 받아 조작하는 하드웨어 제약 없는 협업 리뷰 워크플로우를 검증했습니다.

  • NVIDIA web-viewer-sample 기반으로 Kit 앱(서버) ↔ WebRTC ↔ 자체 제작 웹 클라이언트 구조 구축
  • 웹 클라이언트는 React + TypeScript + Vite로 UI/UX를 새로 제작 (샘플은 구조만 참고)
  • JSON 기반 커스텀 메시지 프로토콜(event_type + payload)을 확장해 씬 로드 요청, 오브젝트 선택 동기화 등 양방향 이벤트 처리 구현

웹 UI에서 오브젝트를 클릭하면 선택 정보가 Kit 앱으로 전달되어 3D 씬 내 오브젝트가 하이라이트되고, 반대로 Kit 앱의 상태 변경도 웹 클라이언트에 반영되는 양방향 동기화 구조입니다.
2

OpenUSD 기반 데이터 파이프라인 개발

개발 의도. FBX/OBJ 등 외부에서 제작된 3D 에셋을 Omniverse에서 바로 활용하려면 OpenUSD 포맷 변환이 필요합니다. 수작업 변환 없이 일관된 파이프라인으로 USD Stage에 편입시켜 곧바로 협업/스트리밍 시스템에서 사용할 수 있도록 했습니다.

  • AssetImporter — 외부 포맷 파일 로드 및 파싱 진입점
  • USDConverter — 지오메트리·머티리얼·트랜스폼을 USD Prim/Attribute로 변환 (pxr.Usd, UsdGeom)
  • StageWriter — 변환 결과를 .usd/.usda Stage 파일로 저장/게시

변환된 에셋은 별도 가공 없이 Omniverse Kit 앱과 웹 스트리밍 뷰어에서 바로 로드해 확인할 수 있었습니다.

3

Omniverse 확장 프로그램(Extension) 개발 및 환경 구축

개발 의도. 웹 클라이언트가 보내는 커스텀 스트리밍 메시지를 Kit 앱 내부에서 실제로 처리할 로직이 필요했습니다. Kit 앱에 탑재되는 자체 Extension을 개발하고, 정상 동작하는 실행 환경을 구축했습니다.

  • omni.ext 프레임워크 위에 커스텀 Extension 구현 — 웹 클라이언트의 event_type/payload 메시지 수신
  • StreamMessageExtension → MessageDispatcher → SceneLoadHandler / SelectionSyncHandler 구조로 라우팅 후 Kit 앱 API(Stage 열기, Selection 변경) 호출
  • 처리 결과를 ~Result / ~Confirmation 메시지로 웹 클라이언트에 응답, Extension 매니페스트 및 로컬 개발 환경 구축
