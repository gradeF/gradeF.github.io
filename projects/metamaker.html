1

JSON 기반 데이터 직렬화/역직렬화 시스템 구축

개발 의도. Unity 기본 타입(Vector3, Quaternion, Color 등)은 JSON으로 기본 직렬화가 되지 않고, VR 콘텐츠 저작 도구 특성상 Transform·머티리얼 색상·텍스트 폰트/내용 등 다양한 커스텀 속성을 안정적으로 저장·복원해야 했습니다. 팀원이 구축해둔 시스템을 이어받아 안정성을 높이는 방향으로 개선했습니다.

직렬화 흐름
flowchart LR
  Obj["오브젝트 속성"] --> DC["TransformData / MaterialColorData / TextData"]
  DC --> Enc["Encoder (Singleton)"]
  Enc --> JSON[("JSON 파일")]
  JSON --> Dec["Decoder (Singleton)"]
  Dec --> DC2["데이터 클래스 복원"]
  DC2 --> Obj2["오브젝트 재적용"]

속성별로 직렬화 대상 데이터 클래스를 분리 설계해, 새로운 속성 타입을 추가하기 쉬워지고 저장/불러오기 과정의 안정성을 확보했습니다.

2

VR 콘텐츠 제작 효율화 툴 개발

개발 의도. 코드를 직접 작성하지 않고도 기획자 등 비개발 인력이 VR 콘텐츠의 오브젝트 배치, 씬 구성, 인터랙션 설정까지 할 수 있도록 해 제작 공정 전체의 효율을 높이고자 했습니다.

  • Unity 에디터 확장 + 런타임 UI를 모두 지원 — 오브젝트 배치/구성 기능과 인터랙션 기능을 직접 담당
  • 어떤 트리거(클릭, 충돌 등)에 어떤 액션(이동, 사운드 재생 등)이 실행될지 GUI에서 정의
  • 설정은 InteractionData로 저장, 런타임에 InteractionRuntime이 읽어 실제 동작으로 실행
개발 지식이 없는 기획자도 직접 VR 콘텐츠를 제작·수정할 수 있게 되어 제작 공정이 효율화됐습니다.
